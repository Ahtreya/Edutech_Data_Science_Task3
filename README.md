# Project Overview
This repository contains the implementation of Task 3: Exploratory Data Analysis (EDA) for the Edutech Solution Data Science Internship. The objective is to extract meaningful insights, identify patterns, and visualise the structure of the classic **Iris Dataset** using Python.
Mini Guide Summary Breakdown:
1. **Summary Statistics**: Generated count, mean, standard deviation, maximum, minimum and quartile threshold of all numerical columns.
2. **Visualise Distribution**: Plotted  stacked histogram with Kernel Density Estimates (KDE) to inspect how  sepal and petal sizes  vary across species.
3. **Correlation Heatmap**: Computed Pearson correlation matrix representing the association of sepal and petal length and width.
4. **Pattern and Trend Detection**: Constructed a comprehensive pairplot to show clear linear clusters separating *Iris-setosa* perfectly from *Iris-versicolor* and *Iris-virginica*.
